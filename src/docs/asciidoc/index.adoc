== 문제

=== 카테고리의 문제 목록 조회
카테고리의 객관식·주관식 문제를 유형과 상관없이 표시 순서대로 반환한다. 서술형은 포함하지 않는다. 보기도 표시 순서대로 정렬되어 있고, 주관식의 `choices`는 빈 배열이다. 정답 정보, 모범 답안, 해설은 포함하지 않는다. 문제가 없는 카테고리는 빈 배열을 반환한다.

operation::questions-list[snippets='path-parameters,http-request,http-response,response-fields']

없는 카테고리는 404로 응답한다.

operation::questions-list-category-not-found[snippets='http-response']

=== 답 제출
고른 보기를 채점해 정답 여부, 정답 보기의 ID, 해설을 반환한다. 채점 결과는 저장하지 않는다.

operation::answers-submit[snippets='path-parameters,request-fields,http-request,http-response,response-fields']

`choiceId`가 없거나 형식이 틀리거나 그 문제의 보기가 아니면 400으로 응답한다.

operation::answers-submit-invalid-choice[snippets='http-response']

없는 문제는 404로 응답한다.

operation::answers-submit-question-not-found[snippets='http-response']

=== 주관식 답 제출
답을 받아 모범 답안과 해설을 반환한다. 입력한 답은 저장하지 않고 자동으로 채점하지도 않는다.

operation::text-answers-submit[snippets='path-parameters,request-fields,http-request,http-response,response-fields']

`answer`가 없거나 공백뿐이거나 5000자를 넘으면 400으로 응답한다.

operation::text-answers-submit-invalid-answer[snippets='http-response']

객관식 문제는 400으로 응답한다.

operation::text-answers-submit-unsupported-type[snippets='http-response']

없는 문제는 404로 응답한다.

operation::text-answers-submit-question-not-found[snippets='http-response']
