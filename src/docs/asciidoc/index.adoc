== 회원

인증은 `access_token` 쿠키로 한다. 가입과 로그인이 `HttpOnly; Secure; SameSite=Lax; Path=/api; Max-Age=3600` 속성으로 쿠키를 설정한다. 토큰 수명은 1시간이다. 유효한 토큰의 남은 시간이 30분 미만이면 그 요청의 응답에 같은 속성의 새 쿠키가 `Set-Cookie`로 붙어 기한이 연장된다 (로그아웃 제외). 연장해도 처음 로그인한 때부터 1일이 지나면 토큰이 만료되므로 다시 로그인해야 하며, 이 절대 기한에 가까워지면 새 쿠키의 `Max-Age`는 3600보다 짧아진다. 1시간 동안 요청이 없으면 토큰이 만료된다. `GET /api/v1/users/me`, `PUT /api/v1/users/me/nickname`, `PUT /api/v1/users/me/password`, `GET /api/v1/users/me/category-stats`, `GET /api/v1/users/me/attempts`, `POST /api/v1/questions/{questionId}/self-grades`만 인증이 필요하고, 나머지 API는 쿠키가 없거나 만료·위조되어도 비회원으로 정상 이용할 수 있다.

토큰의 회원이 없으면 비회원으로 처리한다. 유효한 토큰이라도 그 회원이 없어졌으면 쿠키가 없을 때와 같이 응답하며, 새 쿠키로 연장하지 않는다.

로그아웃하면 모든 기기에서 로그아웃된다. 그 회원이 로그아웃 전에 받은 토큰은 다른 기기의 것까지 모두 서버에서 무효가 되어, 다음 요청부터 회원이 없는 토큰과 같이 비회원으로 처리되고 연장되지 않는다. 다시 로그인하면 새 토큰으로 정상 이용할 수 있다.

회원은 닉네임과 번호(`tag`)를 가지며 다른 회원에게는 `닉네임#번호`로 보인다. 닉네임은 다른 회원과 같아도 되고, 같은 닉네임 안에서 번호로 구분한다. 번호는 그 닉네임의 현재 가장 큰 번호 + 1이며 (없으면 1), 중간의 빈 번호는 채우지 않는다. 가장 큰 번호를 쓰던 회원이 닉네임을 바꾸면 그 번호는 다음 사람이 다시 받을 수 있다. 닉네임은 대소문자를 구분한다 (`Kim`과 `kim`은 다른 닉네임).

=== 회원 가입
이메일, 비밀번호, 닉네임으로 가입하고 바로 로그인 상태가 된다. 이메일은 앞뒤 공백을 지우고 소문자로 저장한다. 닉네임은 앞뒤 공백을 지운 뒤 2~20자(유니코드 code point 기준)여야 하고 쓸 수 있는 문자는 글자, 숫자, 공백, `_` `-` `.`뿐이다. 한글 채움 문자처럼 보이지 않는 글자, 이모지, `#` 같은 다른 기호는 쓸 수 없다.

=== 비밀번호 변경
로그인한 회원 자신의 현재 비밀번호를 확인하고 새 비밀번호로 바꾼다. 새 비밀번호의 규칙은 가입과 같고 (8자 이상, UTF-8 72바이트 이하, 공백만은 안 됨, NUL 문자 없음), 지금과 같은 비밀번호로 바꿀 수도 있다. 바꾸면 로그아웃과 같이 그 회원이 지금까지 받은 토큰이 다른 기기의 것까지 모두 무효가 된다. 요청한 기기는 응답의 `Set-Cookie`로 새 쿠키를 받아 로그인이 유지된다. 성공 응답의 `Set-Cookie`는 새 쿠키 하나뿐이며, 남은 시간이 30분 미만인 쿠키로 요청해도 옛 쿠키의 연장 쿠키는 함께 붙지 않는다. 실패 응답(400, 429)은 다른 API와 같이, 남은 시간이 30분 미만인 쿠키면 연장 쿠키가 붙는다. 성공하면 본문 없이 204로 응답한다.

== 랭킹

랭킹 API는 공개다. 쿠키가 없거나 만료·위조되었으면 비회원으로 처리해 `me` 없이 목록만 반환한다.

점수는 맞힌 문제 수다. 문제마다 가장 최근 풀이 기록 (시각이 같으면 나중에 저장한 기록)이 맞음인 문제를 세며 객관식·주관식·서술형을 모두 넣는다. 삭제된 문제와 삭제된 카테고리의 문제는 점수와 도달 시각 계산에서 모두 뺀다. 관리자 (조회 시점의 role 기준)와 점수가 0인 회원은 랭킹에 넣지 않는다.

순위는 점수가 높은 순이다. 점수가 같으면 지금 점수에 먼저 도달한 회원이 위다. 도달 시각은 점수를 바꾼 (맞혀서 +1 또는 맞혔던 문제를 틀려서 −1) 마지막 기록의 시각이다. 그래도 같으면 먼저 가입한 회원 (회원 ID가 작은 쪽)이 위이며, 같은 등수는 없다. 목록은 상위 50명이고 이메일과 회원 ID는 포함하지 않는다.

`me`는 로그인한 회원 자신의 등수와 점수이며 50위 밖이어도 내려준다. 비회원과 관리자는 `null`이고, 점수가 0인 회원은 `rank`가 `null`, `score`가 `0`이다.

== 관리자

`/api/v1/admin/` 아래의 API는 `role`이 `ADMIN`인 회원만 쓸 수 있다. role은 토큰에 담지 않고 요청마다 DB에서 확인하므로, role을 바꾸면 다시 로그인하지 않아도 바로 반영된다. 관리자 API는 공개 API와 달리 보기의 정답 여부(`correct`)와 모범 답안(`modelAnswer`)을 포함해 응답한다.

삭제는 실제로 지우지 않고 삭제 시각만 남긴다. 삭제한 카테고리·문제는 공개 API와 관리자 API 모두에서 없는 것으로 처리한다 (목록에서 빠지고 단건은 404). 이미 남은 풀이 기록은 내 기록에 그대로 보인다.

로그인하지 않았거나 쿠키가 만료·위조되었으면 401로 응답한다.

=== 카테고리 통계 (관리자)
삭제하지 않은 모든 카테고리를 표시 순서대로 반환하고, 카테고리마다 문제 유형별 풀이 수와 정답 수를 담는다. 모든 회원(관리자 포함)의 풀이 기록을 세되, 한 회원이 같은 문제를 여러 번 풀었으면 가장 최근 기록만 센다 (시각이 같으면 나중에 저장한 기록). 그래서 `solved`는 회원·문제 쌍의 수다. `types`에는 기록이 있는 유형만 `MULTIPLE_CHOICE`, `SHORT_ANSWER`, `ESSAY` 순서로 넣고, 기록이 없는 카테고리는 빈 배열이다. 삭제한 문제의 기록은 세지 않는다. 퍼센트는 계산하지 않는다.
